# Shower Equity

> Auction bathroom time like a tiny real-estate market.

A mobile household app that treats showering as a scarce asset with deeds, bids, and penalties. Members auction morning slots, check in with NFC, and pay fines if they leave early or ghost a reservation. It turns daily bathroom chaos into a lightweight economy of wet-towel accountability.

## Features
- Create room deeds and timed auction slots for every shower
- Check in by tapping an NFC tag to lock the room and start the timer
- Generate early-exit fines that deposit into the household treasury
- Show a shame leaderboard for ghost bookings and wet-towel violations

## Stack
- React Native
- Supabase
- NFCKit

## Getting started
```
npm install, configure Supabase and NFC environment variables, then npm start to run the React Native app.
```
